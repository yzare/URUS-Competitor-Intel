# URUS Global Competitor Landscape

A competitive-intelligence dashboard for URUS (livestock genetics/ag-tech): 67 priority competitors across all 11 URUS operating companies (VAS/DairyComp+PULSE, Alta Genetics, GENEX, Genetics Australia, Jetstream Genetics, PEAK, Trans Ova Genetics, Leachman Cattle of Colorado, SCCL, AgriWebb, Vytelle), five threat vectors, and strategic recommendations.

**Live dashboard:** published as a Claude Artifact (private — ask the owner for the link, or check the share menu on their published artifact).

## Files

| File | Purpose |
|---|---|
| `data.json` | **Source of truth.** Edit this, nothing else. See [SCHEMA.md](SCHEMA.md) for field docs. |
| `URUS_Competitor_Dashboard_v6.html` | Render template — the CSS, tabs, filters, and modal logic. Loads `urus_dashboard_data_v6.js` and never touches `data.json` directly (keeps it openable straight from disk with no server). |
| `urus_dashboard_data_v6.js` | Generated from `data.json` by `build.js`. Do not hand-edit — it gets overwritten. |
| `urus_dashboard_artifact.html` | Generated by `build.js` — a single self-contained file (HTML + CSS + data + render script all inlined) suitable for publishing as a Claude Artifact. Do not hand-edit. |
| `build.js` | Regenerates the two files above from `data.json`. |
| `CHANGELOG.md` | Revision history, newest first. |
| `SCHEMA.md` | Field-by-field documentation for `data.json`. |

## Making an update

1. Edit `data.json` directly, or ask Claude to research and update it.
2. Run `node build.js` to regenerate `urus_dashboard_data_v6.js` and `urus_dashboard_artifact.html`.
3. Add a dated entry to `CHANGELOG.md` describing what changed and why.
4. Bump `meta.revision` and `meta.date` in `data.json`.
5. Commit and push.
6. Publish `urus_dashboard_artifact.html` as a Claude Artifact (update the existing published link rather than minting a new one, so the shared URL doesn't change).

## Automation

A monthly cloud routine clones this repo, re-verifies the dataset against current public sources, runs `build.js`, commits the result, and republishes the Artifact — so the published link and this repo's `main` branch stay in sync automatically. See `CHANGELOG.md` for what each pass found.
